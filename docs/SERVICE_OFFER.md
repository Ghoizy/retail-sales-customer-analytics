# Freelance service offer — Retail analytics and report automation

**Positioning:** I help retail operators turn spreadsheet transaction data into auditable KPIs, easy-to-use dashboards, and repeatable reports. My demonstration is an independent UCI public-data case study, **not a claim of previous paid client delivery**.

## Service packages (starting-price hypotheses, validate through actual conversations)

| Package | Proposed starting price | Scope and delivery |
|---|---:|---|
| Data Audit & Quick Report | Rp750.000 | One worksheet/file, data-quality findings, up to 3 KPIs, PDF or spreadsheet summary, one revision |
| Sales Analytics Dashboard | Rp1.250.000 | One clear source dataset, up to 5 agreed KPIs, one dashboard/report, one revision, basic walkthrough |
| Reporting Automation | From Rp2.500.000 | Multiple recurrent files or scheduled processing, dashboard refresh workflow, handover and tests; quote after review |

*These are proposed trial prices, not market-derived guarantees. Set scope, security requirements, API/cloud costs, and delivery dates after reviewing an anonymized sample.*

## Six questions before quoting

1. What decision should the dashboard help you make each week/month?
2. Which formats and sources do you already have (Excel, Google Sheets, POS exports)?
3. What is one record: invoice line, order, payment, or return?
4. How are returns/refunds, discounts, shipping, and cancellations recorded?
5. How frequently must the data be refreshed, and who will operate it?
6. Can you share an anonymized sample without sensitive customer data?
